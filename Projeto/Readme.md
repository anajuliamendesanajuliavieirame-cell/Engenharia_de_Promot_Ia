Projeto Módulo 3 – Low Code / No Code / Vibecode
Desafio Escolhido
Criação de um Portal Católico Integrado

O desafio proposto consistiu no desenvolvimento de uma plataforma centralizada voltada para a comunidade cristã, reunindo funcionalidades para orações, organização de repertório musical litúrgico e gerenciamento de missas.

Protótipo
Funcionamento da Aplicação

A aplicação foi desenvolvida no modelo Single Page Application (SPA), permitindo que o usuário naveue entre as abas de:

Rezas
Salmos
Músicas
Missas

sem a necessidade de recarregar a página, proporcionando uma navegação mais rápida e fluida.

Destaque do Projeto

Foi implementado um sistema de busca dinâmica na seção de músicas, capaz de filtrar canções por:

título;
artista.

Essa funcionalidade facilita a organização e localização de músicas específicas para cada momento litúrgico.

Plataforma Utilizada
Tecnologia

Desenvolvimento híbrido utilizando:

HTML
CSS
JavaScript
apoio de IA Generativa
Justificativa da Escolha

A abordagem escolhida permitiu:

maior controle sobre a identidade visual do portal;
aplicação da estética temática “verde e ouro”;
execução leve e rápida da lógica de navegação;
funcionamento eficiente diretamente no navegador.

Além disso, a estrutura em JavaScript tornou possível implementar funcionalidades interativas, como filtragem de músicas e gerenciamento de horários de missas e confissões.

Vantagens Identificadas
Velocidade de Desenvolvimento

O uso de templates e auxílio de IA Generativa possibilitou acelerar significativamente a criação da interface e das funcionalidades principais.

Interface Personalizada

A personalização visual foi um diferencial, permitindo aplicar cores e elementos litúrgicos específicos que poderiam ser limitados em plataformas totalmente drag-and-drop.

Centralização de Conteúdo

A plataforma reúne diferentes tipos de conteúdo religioso em um único ambiente digital, facilitando o acesso dos usuários.

Limitações Encontradas
Armazenamento Temporário

Os dados de agendamento de missas ainda são perdidos ao atualizar a página, devido à ausência de banco de dados integrado.

Escalabilidade do Acervo Musical

O gerenciamento manual de centenas de músicas diretamente no código pode se tornar complexo com o crescimento da plataforma.

Interatividade Limitada

Atualmente, o sistema não possui integração com APIs externas para busca automática de letras ou conteúdos musicais.

Próximos Passos
Integração de Áudio

Adicionar players do Spotify ou YouTube para reprodução das músicas diretamente na plataforma.

Implementação de Banco de Dados

Integrar o sistema com:

Firebase;
Google Sheets;
ou outro banco de dados online,

permitindo salvar agendamentos de forma permanente.

Área do Usuário

Criar um sistema de login para que os usuários possam:

salvar orações favoritas;
montar repertórios personalizados;
acompanhar atividades religiosas.
