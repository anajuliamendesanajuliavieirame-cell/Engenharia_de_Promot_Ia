Projeto Módulo 3 – Low Code/No Code/Vibecode
Desafio Escolhido
Criação de um Portal Católico Integrado: O desafio consistiu em desenvolver uma plataforma centralizada para a comunidade cristã, para rezas, organização de repertório musical para missas.
Protótipo
Funcionamento: A aplicação funciona como uma Single Page Application (SPA), onde o usuário navega entre as abas de Rezas, Salmos, Músicas e Missas sem recarregar a página.
Destaque: Implementamos uma busca dinâmica na seção de músicas que filtra por título ou artista, facilitando o encontro de canções específicas para cada momento litúrgico.
Plataforma Utilizada
Plataforma: Desenvolvimento Híbrido (HTML/CSS/JS) com auxílio de IA Generativa.
Justificativa: Escolhemos essa abordagem para garantir controle total sobre a estética "verde e ouro" do site e permitir que a lógica de filtragem de músicas e agendamento de missas e confissões fosse executada de forma leve e rápida no navegador.
Vantagens Identificadas
Velocidade de Desenvolvimento: O uso de templates base permitiu focar no conteúdo e na lógica de navegação em tempo recorde.
Interface Personalizada: Conseguimos aplicar uma paleta de cores litúrgica específica que ferramentas drag-and-drop rígidas poderiam limitar.
Acessibilidade de Conteúdo: A centralização de diferentes tipos de mídia (texto para rezas e lista para músicas) em um único lugar.
Limitações Encontradas
Armazenamento Volátil: No estágio atual, os agendamentos de missas são perdidos ao atualizar a página (necessitando de um banco de dados futuro).
Gestão de Grandes Dados: Gerenciar centenas de músicas manualmente no código pode se tornar complexo conforme o acervo cresce.
Interatividade Limitada: A falta de uma API externa para buscar letras de músicas em tempo real.
Próximos Passos
Integração de Áudio: Adicionar players do Spotify ou YouTube para cada música listada.
Banco de Dados: Conectar o formulário de missas a uma planilha do Google ou Firebase para salvar os agendamentos permanentemente.
Área do Usuário: Criar um login para que cada fiel possa salvar suas orações favoritas.
